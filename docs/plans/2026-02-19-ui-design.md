# Little Artist — Complete UI Design Specification

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A polished, Apple-quality iOS UI for Little Artist — a children's artwork archiving app — following HIG principles with forward-compatible Liquid Glass design language.

**Architecture:** Tab-based navigation (Gallery, Timeline, Milestones, Settings) with modal sheets for capture/edit flows. NavigationStack per tab, adaptive sidebar on iPad.

**Tech Stack:** SwiftUI, SwiftData, iOS 17+, SF Symbols 5, SF Rounded + SF Pro typography, Brand design tokens (`BrandTokens.swift`)

## 1. User Research & Information Architecture

### Target Users
- **Primary:** Parents (25–45) archiving children's artwork
- **Secondary:** Grandparents, extended family viewing shared galleries
- **Tertiary:** Educators documenting student art

### User Personas

**Quick-Capture Parent (60% of sessions)**
- Opens app at the kitchen table, artwork in hand
- Goal: photograph + save in < 30 seconds
- Needs: prominent capture button, minimal required fields, smart defaults

**Browse & Remember Parent (40% of sessions)**
- Leisurely browsing during downtime
- Goal: relive memories, track creative growth, share with family
- Needs: beautiful gallery, timeline, milestones, easy sharing

### Information Architecture

```
Tab Bar
├── Gallery (Home)
│   ├── Child filter chips (horizontal scroll)
│   ├── Artwork grid (2-col LazyVGrid)
```

### Core User Flows

**Quick Capture (< 3 taps to save):**
Gallery → FAB tap → Camera fires → Auto-title generated → Save

**Browse & Share:**
Gallery → Scroll grid → Tap card → View detail → Share button → Activity sheet

**Track Growth:**
Timeline tab → Scroll chronologically → Tap entry → View detail

## 2. Hierarchy, Layout & Platform Patterns

### Visual Hierarchy (5 Tiers)

| Tier | Purpose | Treatment |
|------|---------|-----------|
| **H1** | Screen title | `Brand.displayFont` (SF Rounded .largeTitle bold), `.primary` |
| **H2** | Section header | `Brand.title2Font` (SF Rounded .title2 semibold), `.primary` |
| **H3** | Card title | `Brand.subheadlineFont.weight(.semibold)`, `.primary` |
| **Body** | Descriptions | `Brand.bodyFont` (SF Pro .body), `.primary` |
| **Caption** | Metadata, dates | `Brand.caption2Font` (SF Pro .caption2), `.secondary` |

### Layout Grid

- **Base unit:** 8pt
- **Screen margins:** 16pt (compact), 20pt (regular)
- **Card gap:** 12pt
- **Section spacing:** 24pt
- **Content max-width:** 428pt (iPhone), 600pt (iPad secondary column)

### Navigation Pattern

```swift
TabView {
    NavigationStack { GalleryView() }
        .tabItem { Label("Gallery", systemImage: "photo.on.rectangle.angled") }

    NavigationStack { TimelineView() }
        .tabItem { Label("Timeline", systemImage: "clock.arrow.trianglehead.counterclockwise.rotate.90") }

    NavigationStack { MilestonesView() }
        .tabItem { Label("Milestones", systemImage: "star.fill") }

    NavigationStack { SettingsView() }
        .tabItem { Label("Settings", systemImage: "gearshape.fill") }
}
.tint(Brand.primary)
```

### Depth & Material (Liquid Glass Forward-Compatibility)

| Layer | z-index | Treatment |
|-------|---------|-----------|
| Base canvas | 0 | `Color(.systemGroupedBackground)` |
| Card surface | 1 | `.secondarySystemGroupedBackground` + `.brandCardShadow()` |
| Floating elements | 2 | `ultraThinMaterial` + stronger shadow |
| Modal sheets | 3 | System sheet presentation |
| Alerts/popovers | 4 | System default |

### Safe Area Strategy

- FAB floats 16pt from trailing, 16pt above tab bar
- `.safeAreaInset(edge: .bottom)` adds 80pt clearance for FAB in gallery grid
- Tab bar: system 49pt + device safe area inset
- Large title collapses to inline on scroll via `.navigationBarTitleDisplayMode(.large)`

## 4. Component Specifications

### Button Hierarchy

| Level | Style | Usage | Spec |
|-------|-------|-------|------|
| **Primary** | `Brand.primary` fill, white text, Capsule | One per screen max (main CTA) | Height 54pt, `Brand.headlineFont`, full-radius corners |
| **Secondary** | `Brand.primaryTint` fill, `Brand.primary` text | Supporting actions | Height 44pt, `Brand.subheadlineFont`, cornerRadius 12 |
| **Tertiary** | No fill, `Brand.primary` text | Inline/text actions | No min height, `Brand.subheadlineFont` |
| **Destructive** | `Brand.dustyRose` fill, white text | Delete/remove | Same as Primary dimensions |
| **Ghost** | `ultraThinMaterial`, primary text | Overlay actions | Height 36pt, cornerRadius 8 |

### Card Patterns

**Standard Card (ArtworkThumbnailView):**
- Outer: cornerRadius 18, `.secondarySystemGroupedBackground`, `.brandCardShadow()`
